Sauvegarde…
Une carte « Presque » revient après 1 jour, une carte « Maîtrisé » après 3 jours ; une carte « A revoir » est toujours proposée. Ordre Leitner seulement. Ces délais sont des repères simples, pas des valeurs tirées d'une étude : adaptez-les à votre séquence.

Préparer un brouillon avec une IA

L'IA propose un brouillon. C'est vous qui y mettez le contexte de votre classe, puis qui relisez chaque carte avant de la sauvegarder.

Formule mathématique

Écrire la formule dans le cadre ci-dessous, avec le clavier ou les boutons du clavier mathématique (icône de clavier à droite du cadre). Aucune syntaxe à connaître : ce que tu vois est ce que les élèves verront.

Chargement de l'éditeur de formules…
La formule sera insérée dans le texte de la carte, à l'endroit du curseur. Tu peux mélanger texte et formules dans une même carte.
Attention : le signe $ est réservé aux formules. Pour écrire un prix, utiliser € (ex : 5 €) et éviter « 5$ ou 6$ » dans une carte : le texte entre deux $ serait pris pour une formule.

Code de classe

Les élèves scannent le QR code ou saisissent le code sur flashfwb.vercel.app

Après la date, les élèves ne peuvent plus entrer avec ce code ni enregistrer leur progression. Vous gardez tout dans le tableau de bord, et vous pouvez prolonger le même code.
Ne pas enregistrer de prénoms ? Utiliser des codes élèves

Par défaut, les élèves saisissent leur prénom. Pour ne stocker aucun prénom, donner à chaque élève un code personnel (E01, E02…) à saisir à la place. Vous seul gardez la correspondance code ↔ élève.
